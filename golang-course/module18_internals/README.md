# Module 18: Advanced Internals

This module explores The Go Memory Model, Escape Analysis (Stack vs Heap), Garbage Collection (`GOGC`), Runtime Reflection (`reflect`), and bypassing the type system with `unsafe`.

## Contents
- `main.go`, `memory_model.go`, `reflection.go`: The core reading material.
- `assignment.go`: Hands-on tasks.
- `assignment_test.go`: Test suite to validate your implementation.
- `unsafe_project/`: A project demonstrating the `unsafe` package.
