# Module 17: Build System & Deployment

This module covers Build constraints/tags (`//go:build`), Linker flags (`ldflags` for version injection), Cross-compilation, and Multi-stage Docker builds.

## Contents
- `main.go`, `build_tags.go`: The core reading material.
- `assignment.go`: Hands-on tasks.
- `assignment_test.go`: Test suite to validate your implementation.
- `docker_project.go` & `Dockerfile`: Demonstration of a multi-stage Docker build.
